# cv

Interactive CV and portfolio of Luis Guinea, published at https://luisguinea.com/.

## Site

Static HTML, CSS and vanilla JavaScript. No framework, no build step for the pages, no backend.

| Path | Page |
| --- | --- |
| `/` (`index.html`) | Home: research, experience, education, contact |
| `/cv.html` | Printable CV |
| `/music/` (`music/index.html`) | Music catalogue with chorus previews |
| `404.html` | Not found page, self-contained |

- `css/styles.css`: single stylesheet with design tokens, light and dark themes and print rules.
- `js/strings.js`, `js/i18n.js`: English and Spanish copy, switched in place on the same URL.
- `js/theme-init.js`, `js/site.js`: theme restore before first paint, shared header, mobile menu, bilingual links.
- `js/player.js`: global preview player shared by every page (one `<audio>`, state kept across pages
  in `sessionStorage`). `js/music-page.js` is the `/music/` view on top of it.
- `js/music-data.js`: public catalogue, generated by `data/music-catalog/generate_public_music_data.py`.
  Do not edit by hand.
- `assets/images/`: portrait and release artwork. `assets/audio/previews/`: the 16 verified MP3
  previews (`data/music-catalog/music_preview_manifest.json` holds their sha256). Masters are private
  and never versioned.
- `fonts/`: self-hosted WOFF2, Latin subset (Fontsource 5.3.0): Instrument Serif 400 and italic,
  Inter variable (wght 100 to 900) and IBM Plex Mono 400, all under the SIL Open Font License 1.1
  (`fonts/OFL-*.txt`). No font or script CDN.
- `robots.txt`, `sitemap.xml`: canonical URLs on `https://luisguinea.com/`.

All internal links and asset URLs are relative, so the same files work at the domain root and under a
project-site subpath such as `https://lcguinea.github.io/cv/`. The only exception is `404.html`, which
GitHub Pages serves at any depth and therefore links to `/`.

## Local preview

Serve the repository root (or the built `_site/`) with any static server that supports HTTP Range
requests; previews need `206 Partial Content` to seek and to restore their position across pages.
Python's `http.server` does not support Range.

## Publication

`.github/workflows/pages.yml` publishes through GitHub Pages with GitHub Actions on every push to
`main` (or manually):

1. `python3 tools/build_site.py --out _site` copies an explicit allowlist of tracked files into
   `_site/`: the pages, CSS, JavaScript, fonts and licences, `robots.txt`, `sitemap.xml`, the portrait
   and only the artwork and previews that `js/music-data.js` publishes. It then validates the result
   and fails on any other file, Markdown, tests, catalogue data, scripts, audio other than the 16
   verified previews, or a broken local reference.
2. `tests/test_site_artifact.py` and the public catalogue contract run as focused checks.
3. `actions/upload-pages-artifact` and `actions/deploy-pages` publish `_site/` as is (no Jekyll).

Nothing is published until Pages is enabled in the repository settings with "GitHub Actions" as the
source. The custom domain `luisguinea.com` is set in those settings, not with a `CNAME` file.

## Checks

Focused tests, standard library only (behaviour tests also need Node.js):

```sh
python3 tools/build_site.py --out /tmp/site
python3 -m unittest tests/test_site_artifact.py tests/test_site_navigation_i18n.py tests/test_global_player.py tests/test_external_links.py
python3 data/music-catalog/check_public_music.py
python3 data/music-catalog/test_public_catalog_contract.py
```

## Sources of truth

the site.
